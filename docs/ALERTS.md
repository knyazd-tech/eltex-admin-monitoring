# Alert rules

The package contains 18 Prometheus alert rules.

- `EltexExporterDown`
- `EltexFastCollectionFailed`
- `EltexLegacyCollectionFailed`
- `EltexCollectionStale`
- `EltexPONNotOperational`
- `EltexWANDown`
- `EltexPONRxPowerLow`
- `EltexPONRxPowerCritical`
- `EltexPONRxPowerHigh`
- `EltexPONTxPowerOutOfRange`
- `EltexPONTemperatureHigh`
- `EltexPONTemperatureCritical`
- `EltexMemoryUsageHigh`
- `EltexLANPortDown`
- `EltexWiredInterfaceErrors`
- `EltexWiFiTransmitErrorsHigh`
- `EltexPONFECErrorsGrowing`
- `EltexPONHECErrorsDetected`

Review thresholds before enabling notifications in production.
